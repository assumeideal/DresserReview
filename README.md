# ✨ Dressing Table Review Web App

An interactive, minimal, and aesthetic web application for reviewing, rating, and sharing feedback on dressing table designs.

## 🚀 How to Use & Share

### Option 1: Send the single HTML file directly
You can simply send the `index.html` file to your friend via WhatsApp, AirDrop, email, or cloud drive (Google Drive / Dropbox). When she double-clicks it on her phone or computer, it will open directly in her browser—no installation or internet hosting required!

### Option 2: Host for Free Online (Shareable Link)
To send a regular web link:
1. **Netlify Drop**: Go to [app.netlify.com/drop](https://app.netlify.com/drop) and drag-and-drop the `dressing-table-app` folder. You will get an instant live public URL in 5 seconds.
2. **Vercel / GitHub Pages**: Deploy with one click to Vercel or GitHub Pages.

## ✨ Features Included
- **Step-by-Step Slide Mode**: Focuses on one dressing table at a time with smooth transitions, progress tracking, keyboard arrows, and mobile swipe gestures.
- **Scroll All View**: Switch anytime to view all 10 items on a single scroll page.
- **Interactive Rating Slider**: 1 to 10 scale with real-time vibe tags (*Not feeling this one* → *Obsessed!*).
- **Single Feedback Box**: Dedicated input for what she likes, dislikes, or any notes.
- **Direct Retailer Links**: Instant link to view each product on Dusk, Next Home, Furniture123, Melody Maison, Oak Furnitureland, etc.
- **Automatic Summary Leaderboard**: Ranks all options from #1 favorite down.
- **1-Click Return Feedback**:
  - 💬 **WhatsApp**: Pre-fills a beautifully formatted message with rankings and quotes.
  - 📋 **Copy to Clipboard**: Quick copy of the whole review.
  - ✉️ **Email**: Direct email template.
